    <h4>If you are a Designer 👨🏻‍🎨</h4>
    <p>
      Every new project starts from the <a href="https://www.figma.com/files/folder/44816180" target='_blank'>Project Template</a> folder in Figma. It has three files:
    </p>
    <ul>
      <li><a href="https://www.figma.com/design/MgGtqLFXFZVTatB9aXjpnM/Research?node-id=0-1" target='_blank'><b>1. Research</b></a>: moodboards, wireframes and other studies.</li>
      <li><a href="https://www.figma.com/design/rkRWOtSBgEd6wdfInQU2Oi/Design-System?node-id=0-1" target='_blank'><b>2. Design System</b></a>: the foundations (variables, text styles, effect styles) and the components (atoms, molecules, organisms and templates). It is published as a library.</li>
      <li><a href="https://www.figma.com/design/Gdq9z2aWrI8nIITaYGno0c/Mockups?node-id=5-2" target='_blank'><b>3. Mockups</b></a>: the final screens and prototypes, built with the library's components.</li>
    </ul>
    <p>The components are bound to the variables and styles, so when the foundations change, every component follows the new branding.</p>
    <br />
    <span className="sub-heading">1. Duplicate the Project Template</span>
    <p>Duplicate the Project Template folder and rename it to the new project's name. The three files inside keep their names.</p>
    <br />
    <span className="sub-heading">2. Apply the new branding</span>
    <p>Open <b>2. Design System</b> and change its foundations to the new project's branding:</p>
    <ul>
      <li><b>Variables › Colors</b>: primary, accent, neutral, success and danger, in both the Light and Dark modes.</li>
      <li><b>Variables › Spacing & Sizes</b>: space, sizes, font sizes and radii.</li>
      <li><b>Text styles</b>: font family, weights and line heights of Headline, SubHeading and Paragraph.</li>
      <li><b>Effect styles</b>: mainShadow and cardShadow.</li>
    </ul>
    <p>Only change values. Don't detach components or type values into them, or they stop following the foundations.</p>
    <br />
    <span className="sub-heading">3. Publish the library</span>
    <p>In <b>2. Design System</b>, open <b>Assets › Libraries</b> and click <b>Publish</b>. Publish again after every change, then accept the update in the files that use the library.</p>
    <br />
    <span className="sub-heading">4. Connect Research and Mockups</span>
    <p>Open <b>3. Mockups</b>, go to <b>Assets › Libraries</b>, turn on the new project's Design System library and turn off the Project Template's. Do the same in <b>1. Research</b>.</p>
    <p>If a file already has components from the template, they still point to the Project Template library: use <b>Swap library</b> in the Libraries window to move them to the new one.</p>
    <br />
    <span className="sub-heading">5. Start designing</span>
    <p>The <b>Assets</b> tab lists every component in the library. Drag them onto the canvas and change their properties (Variant, State, Icon, Size) in the right sidebar.</p>
    <br />
    <span className="sub-heading">6. Hand off to developers</span>
    <p>
      Developers apply the same branding with <code>setupTheme</code> (step 5 of the developer guide above): Colors go into <code>userColors</code>; Spacing & Sizes, font weights and line heights into <code>userSizes</code>; the font family into <code>fontFamily</code>; and the effect styles into <code>userShadows</code>.
    </p>
